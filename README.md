### 05 · SafeWatch AI — Women Safety CCTV Surveillance Detector 🛡️
> An intelligent, real-time video surveillance and threat detection system engineered specifically to enhance women's safety in public spaces, transport hubs, and campus environments.

The system continuously monitors live CCTV feeds, tracks multi-person interactions, analyzes body motion and gestures using skeletal pose estimation, accurately distinguishes harmless social interactions from physical assaults, and automatically dispatches geo-stamped emergency alerts to authorities and designated contacts.

**Core Capabilities:**
- 🎯 **Real-time CCTV Monitoring** — Processes live multi-camera feeds with low-latency inference
- 🦴 **Pose Estimation** — MediaPipe skeletal keypoint tracking for all detected persons
- ⚠️ **Threat Classification** — LSTM-based sequence classifier trained on threat-interaction datasets
- 📍 **Geo-stamped Evidence** — Auto-captures timestamped incident clips with location metadata
- 🚨 **Emergency Alert Dispatch** — Instant SOS via FastAPI microservice to authorities & contacts
- 📷 **Multi-Camera Support** — Scalable across N concurrent CCTV streams
- 🔍 **Motion Vector Analysis** — Proximity, velocity, and directional motion heuristics

**Stack:** Python · OpenCV · YOLOv8 · MediaPipe · PyTorch · LSTM · FastAPI · React

## ⚙️ Getting Started

```bash
# Clone the repository
git clone https://github.com/reddy895/Own-portfolio.git
cd Own-portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
